# Assumptions

- One bounded synthetic usability session is used.
- The log contains step ID, timestamp, screen, action, target, duration and outcome.
- 15 seconds or more is a long pause.
- Failed actions are friction signals.
- Immediate repeated actions suggest possible difficulty.
- Returning to an earlier screen suggests possible backtracking.
- Detection is deterministic and explainable.
- AI is used only for the required summary task.
